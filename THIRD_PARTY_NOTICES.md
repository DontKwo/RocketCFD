## Open-Source Dependencies

- **NumPy** (`BSD-3-Clause`): Array numerics and vector geometry math.
- **SciPy** (`BSD-3-Clause`): Scientific interpolation and numerical routines.
- **Matplotlib** (`PSF-based`): Engineering profile and regime charts rendered cleanly for the Studio UI.
- **Trimesh** (`MIT`): Triangular mesh loading, repair, and parametric assembly.
- **PyMeshFix** (`MIT`): Watertight surface repair for STL/OBJ/PLY geometry inputs.
- **Shapely** (`BSD-3-Clause`): Planar fin extrusion polygons.
- **NetworkX** (`BSD-3-Clause`): Dependency ordering utilities.
- **Pint** (`BSD-3-Clause`): Physical unit conversions.
- **PyVista** (`MIT`): VTK surface and volume field extraction helpers.
- **Requests** (`Apache-2.0`): Optional remote deployment HTTP client.
- **OpenFOAM (Optional Runtime Solver)** (`GPL-3.0`): External CFD solver suite installed separately by users; see the [OpenFOAM Installation Guide](docs/OPENFOAM_INSTALLATION.md).
